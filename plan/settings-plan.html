Settings simplification plan

The Settings area has 10 entries, three places to sign in, and different menus in portrait and landscape. This plan cuts it to 7 entries in 4 groups, with the same menu in both orientations. Tick items as you finish them. Your ticks are saved in this browser.

What is confusing today

  • 110 entries in one menu. Theme, Timeline BG, Audio, Category, Quick Messages, Leave Mgmt, General, Account, Data Mgmt and About.
  • 2Account and Data Mgmt overlap. Both have Google sign-in and backup. Sign-in also appears in the profile header at the top, so there are three places.
  • 3Portrait and landscape differ. Portrait groups items under Appearance, Preferences and System. Landscape shows one flat list in another order. Leave Mgmt appears only in landscape.
  • 4General is a grab bag. Daily start time, notes folder locks (with three sub-options and a reset), Disable Past Timers and Disable Past Tasks have little in common.
  • 5The code repeats itself. index.tsx renders every section twice, once for portrait and once for landscape, and the styles file is 2,072 lines. Every change has to be made twice.

What changes on each page

One card per current Settings page: what it does now, what changes, and what else is affected.

Theme

MERGED INTO APPEARANCE
Now
Color presets, filler, slider and text colors, live landscape preview.
Change
Becomes the first block on the Appearance page. Content stays the same.
Affects
Menu entry, page title. The colors still drive the timer screens.
Risk
Low. The landscape preview needs the same width as before.

Timeline BG

MERGED INTO APPEARANCE
Now
Separate full-screen page (1,422 lines) for time-of-day background colors.
Change
Stays a full-screen sub-page, but is opened from a row on the Appearance page.
Affects
Menu entry and the back button behavior (back returns to Appearance).
Risk
Low. Saved slots are unchanged.

Audio

RENAME TO SOUND
Now
Completion sound choice and repeat count.
Change
Only the name in the menu and page title.
Affects
Nothing else. The completion screen and timer popup read the same saved values.
Risk
None.

Category

MERGED INTO LISTS
Now
Add, edit, enable or disable and reorder categories (drag list).
Change
Becomes a block on the Lists page. Same behavior.
Affects
Timer, task and completion screens use the category list and colors, so they are unaffected as long as the saved data is unchanged.
Risk
Medium. It uses the older drag library, so moving it into a longer page can make the drag feel different. Switch it to the newer list library when you move it.

Quick Messages

MERGED INTO LISTS
Now
Add, edit and reorder the reusable comment chips.
Change
Becomes a block on the Lists page.
Affects
Task comments use these chips and are unaffected.
Risk
Medium, same drag-library note as Category.

Leave Mgmt

MERGED INTO LISTS
Now
Mark leave or holiday dates with a reason. Landscape sidebar only.
Change
Becomes "Leave days" on the Lists page, and appears in portrait for the first time.
Affects
Recurring tasks skip leave days, so test a recurring task after the move. New in portrait: the page must fit a narrow screen (682 lines, written for landscape first).
Risk
Medium. Portrait layout needs checking.

General

REORDER AND CLARIFY
Now
Daily start time, notes folder locks (require code every time, max wrong attempts, reset all locks), Disable Past Timers, Disable Past Tasks.
Change
Reorder into "Day" (start time), "Past dates" (two toggles) and "Privacy" (notes locks). Add a one-line explanation to each.
Affects
No saved data changes. The day start time changes which logical day timers and tasks belong to, so it must keep using the same storage key.
Risk
Low.

Account

MERGED INTO BACKUP & ACCOUNT
Now
Login with Google, sync status, sign out, "Offline Backup" card.
Change
Becomes the top block of the Backup & Account page. Sign-in is the single place to sign in.
Affects
The profile header at the top of Settings, the "SYNC" pill on the menu card, and the landscape default page (it opens on Account today).
Risk
Medium. Google sign-in only works in a development build, not in Expo Go.

Data Mgmt

MERGED INTO BACKUP & ACCOUNT
Now
Cloud sync to Google Drive (sign in, back up, restore, auto-backup time), Export, Local cleanup (clear timers, clear tasks, wipe all).
Change
Below the account block: Back up now, Restore, Auto-backup time, Export. Cleanup moves to a red "Danger zone" at the bottom.
Affects
Auto-sync on app start and resume keeps working because the service does not change. The "clear all" confirmation is reused.
Risk
Medium. This page deletes data, so test Cancel and the typed confirmation after moving it.

What stays the same

Your data

  • No storage keys are renamed or removed, so nobody loses settings, timers, tasks or notes.
  • Google Drive backups made before the change still restore.

Other screens

  • Timers, tasks, goals, Live Focus and the completion screens are not touched.
  • App.tsx keeps all state. Settings still receives the same props.

Decide before starting

  1. Menu Is 7 entries right, or do you want 5 (also merge General into Backup & Account, and About into the profile header)?
  2. Lists Three collapsible blocks on one page, or tabs at the top? Collapsible blocks are simpler to build.
  3. Notes locks Keep them in General, or move them to the Notes screen where they are used?
  4. Timeline BG Keep it as a sub-page, or make it a short block inside Appearance?
  5. Order Start with Phase 1 and 2 only, then look at the result before the rest?
